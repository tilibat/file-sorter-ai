# 🗂️ AI-сортировщик файлов (File Sorter AI)

**Умный инструмент для автоматической организации файлов с элементами искусственного интеллекта.**

> 📚 *Учебный проект для практики в компании [Texel](https://texel.graphics)*

---

## 📋 Описание

AI-сортировщик файлов — это Python-приложение для автоматической организации файлов в папке загрузок (Downloads) и других директориях. Программа сортирует файлы по категориям, находит дубликаты и предлагает умное переименование.

### ✨ Возможности

- **🗂️ Сортировка по категориям** — автоматическое распределение файлов по папкам (Изображения, Документы, Видео, Аудио и др.)
- **✏️ Умное переименование** — генерация понятных имен файлов на основе даты и типа (с возможностью подключения OpenAI API)
- **🔍 Поиск дубликатов** — обнаружение файлов-копий по хешу содержимого
- **👁️ Автоматический режим** — отслеживание новых файлов и мгновенная сортировка (watchdog)
- **⚙️ Гибкая настройка** — конфигурация категорий, путей и правил через `.env`

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/tilibat/file-sorter-ai.git
cd file-sorter-ai
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации

```bash
cp .env.example .env
# Отредактируйте .env при необходимости
```

## 📖 Использование

### Интерактивный режим

```bash
python main.py
```

Откроется меню с выбором действий:
1. Сортировать файлы по категориям
2. Найти дубликаты
3. Переименовать файлы
4. Запустить автоматический режим
5. Показать конфигурацию

### Командная строка (CLI)

```bash
# Разовая сортировка файлов
python main.py --sort

# Автоматический режим (отслеживание новых файлов)
python main.py --watch

# Поиск дубликатов
python main.py --find-duplicates

# Умное переименование
python main.py --rename

# Указать другую папку
python main.py --sort --folder ~/Desktop

# Показать конфигурацию
python main.py --config

# Справка
python main.py --help
```

## ⚙️ Конфигурация

### Файл `.env`

```env
# Путь к папке для сортировки (по умолчанию ~/Downloads)
SOURCE_FOLDER=/path/to/your/folder

# OpenAI API ключ для умного переименования (опционально)
OPENAI_API_KEY=sk-xxx

# Режим отладки
DEBUG=False
```

### Категории файлов (`config.py`)

По умолчанию файлы сортируются по следующим категориям:

| Категория | Расширения |
|-----------|------------|
| 📷 Изображения | .jpg, .png, .gif, .svg, .webp... |
| 📄 Документы | .pdf, .doc, .docx, .txt, .xlsx... |
| 🎬 Видео | .mp4, .avi, .mkv, .mov... |
| 🎵 Аудио | .mp3, .wav, .flac, .aac... |
| 📦 Архивы | .zip, .rar, .7z, .tar.gz... |
| 💿 Программы | .exe, .msi, .dmg, .deb... |
| 💻 Код | .py, .js, .html, .css... |
| 🔤 Шрифты | .ttf, .otf, .woff... |
| 📁 Другое | всё остальное |

Категории можно изменить в файле `config.py`.
